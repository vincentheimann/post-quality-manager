## External services (readme.txt section)

```
== External services ==

This plugin sends content to two services that you set up and control. Nothing is sent before you enter a webhook address in the plugin's settings or connect an n8n instance, and nothing is sent to the plugin's author.

**Your n8n instance.** When you run a command on a post, or a schedule you set runs one, the plugin calls the n8n webhook you configured with the post's title, excerpt, content and link, the command, your site's callback address, the settings text you wrote in the plugin (Editorial Standards, Website Context, per-agent instructions, model choice), the webhook token, and the post's Yoast SEO fields when Yoast is active. Your workflow can read the same post data through the plugin's REST API and writes the result back. If you connect your n8n instance by API key on the n8n Workflow page or in the setup guide's Connect your n8n step, the plugin also calls that instance when you click Connect or Check again: through n8n's public API with the key, it lists one workflow and checks that two API endpoints exist, changing nothing on n8n, and names itself in the user agent of every call. If you let the setup guide set the workflow up, the plugin uses the same key to create the workflow and its credentials in n8n (the webhook token, your Anthropic API key and, on Pro, your WordPress username with a new Application Password for Rewrite) and to activate the workflow; if that setup fails, it removes the workflow and credentials it created. If you let the plugin manage a workflow you set up by hand, it reads your active workflows with the key to find the one at your webhook address and stores the IDs of that workflow and its credentials, changing nothing on n8n. The key is stored in your site's database until you click Forget key or delete the plugin; the address stays until the plugin is deleted; use an n8n API key created for this site alone, with an expiration date. n8n is run by you, self-hosted or on n8n Cloud: terms https://n8n.io/legal/ and privacy https://n8n.io/legal/privacy/.

**Your AI provider.** The workflow sends the post text and your settings text to the AI provider whose API key you configured in n8n (Anthropic by default; OpenAI or Google if you choose them in the workflow). Their terms and privacy policies apply: Anthropic https://www.anthropic.com/legal/consumer-terms and https://www.anthropic.com/legal/privacy; OpenAI https://openai.com/policies/; Google https://ai.google.dev/terms. When the setup guide sets the workflow up, the plugin forwards the Anthropic API key you type once: one request from your site to api.anthropic.com checks it (it lists one model, with no post content), then the key goes into the n8n credential. The plugin never stores it.

**Freemius (Pro licenses and optional usage data).** Pro licenses are sold and checked through Freemius; with a license key entered, your site's address, the plugin version and the key are sent to verify it. On activation the plugin asks whether to share usage data with the author through Freemius: the first and last name and email address of the WordPress user who opts in (always included), the site address and title, WordPress, PHP and plugin versions, site language, activation state and deactivation reason, and a list of the site's plugins and themes (names, slugs, versions, active or not; on by default when opting in, optional when activating a license). This is off until you opt in, the screen can be skipped, and the free features do not depend on it. Terms https://freemius.com/terms/ and privacy https://freemius.com/privacy/.

Full policy: https://postquality.com/privacy
```

## Suggested privacy-policy text (`wp_add_privacy_policy_content()`)

Registered on `admin_init`, shown to site owners under Settings → Privacy → Policy Guide:

```
Post Quality Manager sends post content to services you configure. When a review is run, the post's title, excerpt, content and link, your Editorial Standards and Website Context text, and (if Yoast SEO is active) its SEO fields are sent to your own n8n instance, which forwards them to the AI provider you chose. The results are stored on this site in the plugin's reviews table until the plugin is deleted. If an administrator connects an n8n instance by API key, the instance address and the key are stored on this site, and the plugin calls that instance's API only when asked to check the connection, to set the workflow up or to manage a workflow set up by hand (which it only reads). Setting it up sends the Anthropic API key once to Anthropic to check it and passes it into an n8n credential without storing it on this site; on Pro, it also creates an Application Password for the administrator's account, kept in that n8n credential so the workflow can save Rewrite results. The plugin keeps a monthly count of AI actions per user. It sets no cookies and collects nothing about site visitors. If a Pro license is entered, the site address, plugin version and license key are sent to Freemius to verify the license; usage data (the opting-in user's name and email, site details and versions, and by default the list of installed plugins and themes) is shared with the plugin's author only if an administrator opted in.
```
