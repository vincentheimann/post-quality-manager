# Release Checklist

1. Review the open "Release PR" generated by the `release-please` GitHub action (the action itself is still to be added — epic `epic-delivery-pipeline` in `_bmad-output/`; until then, cut the release by hand following the same checks).
2. Ensure the generated CHANGELOG accurately reflects the merged Conventional Commits.
3. Once the Release PR is merged, verify that the GitHub Actions job runs and creates the new GitHub Release and version tag.
4. Verify the plugin zip file is correctly attached to the GitHub Release.
