## 2. Decisions only the owner can take

- **D1 Prefix length (#13).** I recommend renaming every global and stored name to a prefix of 4 or more letters before entry 8, with a one-time migration for options, capabilities and the table. There are no real installs yet (`docs/user-paths.md:6`), so the rename is cheapest now, and every later rename needs a migration on live sites. C names 3-letter prefixes explicitly, and story 38's own aim is to close gaps "before submission, not during a weeks-long review loop". It overrides 38's "stored settings keys" boundary, and it touches the stripper's exact `pqm_fs()->is__premium_only()` match (`bin/build-free.php:122`) and every harness. The alternative is to submit as is and rename only if the reviewer asks.
- **D2 Translations (#17).** I recommend dropping `Domain Path` and `pqm_load_textdomain()` in story 38. Directory installs get language packs from translate.wordpress.org, and the Pro build gets them through the SDK's WordPress.org translation fetch (`vendor/freemius/includes/class-fs-plugin-updater.php:909`, org-compliant freemium only). This clears 2 warnings. It reverses the PHP half of entry 6, which the owner verified.
- **D3 AIProvider warning (#18).** I recommend keeping the direct key check. It is a key validation, not a prompt, and `wp_ai_client_prompt()` needs WP 7.0, above the 6.6 floor. Record it as an accepted warning with that reason, beside W1/W2.
- **D4 Readme/asset updates between releases (#40).** I recommend no asset-update action at launch, and a patch release when a new WordPress major needs a "Tested up to" bump. Add a manual-dispatch readme-and-assets SVN job later if those bumps outpace releases.
- **D5 Live Preview (#34).** I recommend skipping it at launch: a Playground preview cannot reach an n8n, so it would show an empty plugin. Revisit with the story 49 demo data.
- **D6 Contributors (#19).** I recommend keeping `postquality` only, with the API upload as the SVN source so Freemius adds nothing.
- **D7 What the fresh public repository carries.** This is not a directory rule. The history-rewritten repository will publish internal records: `memory/`, `_bmad-output/`, `.claude/`, `PORTFOLIO.md` and its PDF, and `docs/distribution.md` with Freemius pricing IDs, payout and DNS details. I recommend the owner settles this list inside chore 87, since that rewrite runs only once.
- **D8 First listing's changelog and Upgrade Notice (#25, #26).** I recommend one short "first release on WordPress.org" entry plus a link to GitHub Releases, and no Upgrade Notice. Story 15's upgrade notes target 2.x/3.x upgraders, who do not exist in the directory.
