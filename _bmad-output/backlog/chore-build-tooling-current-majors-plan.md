## Intent

**Problem:** The React pages build, lint and unit-test with `@wordpress/scripts` 30.27.0 and `typescript` 5.3.3. The registry's latest is 37.1.0 (2026-11-04). The ticket's "current major is 35" came from `/lcm`'s `npm outdated`, which hides versions whose `engines` this PC's Node 22.14.0 does not meet: 36.0.0 and later need Node `^22.22.2 || ^24.15.0 || >=26`. typescript-eslint, which the lint runs on, supports TypeScript `>=4.8.4 <6.1.0`, so TypeScript 7 still breaks it (the reason for the 5.3 pin, story 5.8).

**Approach:** Move `@wordpress/scripts` to its current major (37) and `typescript` to 6.0.x, the newest typescript-eslint supports. Resolve every new lint report in code, and keep the built pages' WordPress script dependencies the same, so the 6.6 floor holds. Then walk the Dashboard, Post Reviews and the setup dialog on the showcase, Free and Pro builds. Fix `/lcm`'s build check so it reads the registry's latest version.

## Boundaries & Constraints

**Always:** The 181 unit tests keep their assertions. Each built `*.asset.php` keeps the dependency handles main's build has, so nothing newer than WordPress 6.6 is needed. The tests' React stays the one WordPress 6.6 ships, 18.3.1. CI and the release workflow run the same `npm` scripts on a Node they accept.

**Never:** No rule disabled to make lint pass; an `eslint-disable` line only where one exists today for the same reason. No React feature or page change, no PHP, no `Requires at least` change. No new runtime dependency: the shipped zip carries only the build.

**Decision (owner, 2026-11-06): the major and the runner.** `@wordpress/scripts` 37 (37.1.0 today), keeping Jest: `test:unit` runs `wp-scripts test-unit-jest tests/js`, and the migration guide's tested combination becomes our own devDependencies (`jest`, `jest-environment-jsdom` and `babel-jest` 30.5.0, `@wordpress/jest-preset-default` 14.2.0, `@babel/core` 7, `@wordpress/babel-preset-default` 8.55.0), with a `jest.config.cjs` and an `eslint.config.cjs` that keeps Jest's lint rules through `eslint-plugin-jest`. The tests stay as they are; moving them to Vitest is a later story, if one is filed.

**Decision (owner, 2026-11-06): Node on this PC.** The agent runs `winget upgrade --id OpenJS.NodeJS.22` (22.14.0 → 22.23.4, the 22 line CI resolves) before the build.

**Decision (owner, 2026-11-06): plan size.** Keep the full plan; the `/lcm` step-6 fix ships with it.
