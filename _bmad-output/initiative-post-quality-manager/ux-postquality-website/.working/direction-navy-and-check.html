Direction: Navy and check

Brand-led, confident. Home page of postquality.com, an option to react to, not a decision (story 57 UX pass, 2026-10-22).

The brand icon's own palette carries the page: a full-bleed navy band with large, bold white type, and the green check used only where something is confirmed (ticks, one highlight, the focus ring). It is the direction closest to a SaaS landing page, with one clear action, bigger type and the Dashboard floating over the band so the visitor lands inside the plugin. It stays honest: the pre-launch state says plainly that the plugin is not installable yet, and "What you need" follows the capture straight away.

Honest nudges used (labelled candidates from the brief)

  1. Prerequisites up front. "What you need" sits directly under the capture. After launch, a one-line version sits above the Install button, so no install action comes before it.
  2. You hold the keys. Hero tick "Your content goes nowhere else", repeated as the trust line under the flow in How it works.
  3. The free plugin is the trial. Hero tick and the Free vs Pro heading.
  4. 14-day money-back guarantee, under the plan cards.
  5. Nothing deleted if Pro lapses, beside the guarantee.
  6. Plain status. "Not installable yet" and "you hear once" under the pre-launch action.

Not used: countdowns, scarcity, social proof (none exists yet), any AI-cost figure (the worked example is pending, story 49).

The icon on navy

The icon file stays untouched. Where it sits on the navy band, a 1.5 px white ring is drawn outside the tile (a CSS box-shadow on the wrapper, never inside the SVG), so the square reads as a tile again. White already belongs to the mark, so no third colour enters. On white and tinted surfaces the icon goes bare.

Colours and contrast

  • #1b2a41navy: band, Pro card, headings, button text
  • #00a32acheck green: ticks, h1 bar, focus ring only
  • #fffffftype on navy, primary button, keyline
  • #2a3649body text on white (12.19:1)
  • #4f5b6emuted text on white (6.88:1)
  • #dfe6eflead on navy (11.49:1)
  • #c8d2e0muted on navy (9.46:1)
  • #263a59lighter navy: hover, inner rules
  • #f3f5f8tint sections (navy text 13.22:1)

Primary button: 14.44:1. Navy text on a white fill on the band; the inverse (white on navy) on white sections. Focus ring: 3 px green, 4.31:1 on navy and 3.35:1 on white. Green never fills behind site text: white on #00a32a is only 3.35:1.

Phone decisions in this direction

  • Header: the lockup keeps the full name; the three links wrap to their own row under a hairline. No menu button, no script.
  • Hero: left-aligned, h1 36 px, both actions full width with the primary first; the ticks stack.
  • Capture: a second, narrower image of the same Dashboard (tiles and the top of Fix next, no admin menu). The full screen shrunk to phone width would be unreadable.
  • Icon: the white keyline stays on the band at 32 px.
  • First screen (844 px): header, hero, both actions, the ticks and the top of the capture, which still floats over the band's edge.
  • What you need starts right under the capture caption, before any install action.
