# Security policy

## Supported versions

Security fixes go into the latest release of Post Quality Manager. Older releases are not patched; update to the latest version from the WordPress.org directory or from GitHub Releases.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Preferred: GitHub's private vulnerability report on this repository ("Security" tab → "Report a vulnerability").
- Or by email: hello@postquality.com.

You will get an answer within 2 business days. Include the plugin version, the WordPress and PHP versions, and the steps to reproduce. Once a fix is released, you are credited in the release notes unless you ask not to be.

## Scope

The plugin and the n8n workflow template it ships. Your own n8n instance, your AI provider account and your WordPress hosting are outside this policy; report problems there to their providers.
